Halloran's connection details were documented properly, in a 200-page technical
handbook that almost nobody read all the way through. Their engineers wanted
something that answered the common questions before the phone rang.

## What we did

Rather than one long film, we made six fifteen-second loops — one per
connection type — that play silently on the relevant product page. Each loop
shows the same three beats: components apart, components together, load path.

Because every loop was built from the same master model, the geometry is
consistent between them, and the handbook illustrations were exported from the
same file at no extra cost.

## Outcome

Halloran's technical support team now answer connection queries with a link.
The loops were later cut together into a single reel for their stand at
UK Construction Week.
